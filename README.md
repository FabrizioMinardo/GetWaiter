# 🍽️ Get Waiter — Sistema de atención para restaurantes

Sistema web de atención para restaurantes que permite a los clientes realizar solicitudes directamente desde su mesa mediante un código QR.

El sistema busca facilitar la comunicación entre clientes y personal del restaurante y, al mismo tiempo, registrar las interacciones para obtener información sobre el uso del servicio.

## 📌 Descripción

El cliente escanea el código QR asociado a su mesa y accede a una interfaz web desde la que puede realizar distintas solicitudes.

Las acciones realizadas se registran y se envían al personal del restaurante mediante un bot de Telegram, permitiendo identificar la mesa y el tipo de solicitud.

Además, la información registrada puede utilizarse para analizar el uso del sistema y detectar oportunidades de mejora en la operación.

## 🚀 Funcionalidades

* 🛎️ **Llamar al mozo:** permite solicitar atención indicando automáticamente el número de mesa.
* 💰 **Pedir la cuenta:** notifica al personal que la mesa desea solicitar la cuenta.
* 📋 **Menú:** permite acceder al menú del restaurante desde el navegador.
* ✍️ **Dejar una opinión:** redirige al perfil del restaurante en Google Maps para dejar una reseña.
* 📶 **Wi-Fi:** permite acceder a la información necesaria para conectarse a la red Wi-Fi del establecimiento.
* 📸 **Instagram:** acceso directo al perfil de Instagram del restaurante.
* 📊 **Registro de interacciones:** almacena las acciones realizadas por los clientes para generar información sobre el uso del sistema.

## 🛠️ Tecnologías utilizadas

* **HTML5, CSS3 y JavaScript:** estructura, diseño e interacción de la aplicación.
* **Google Apps Script:** procesamiento de acciones y almacenamiento de información.
* **Google Sheets:** registro y consulta de las interacciones realizadas.
* **Fetch API:** comunicación entre la aplicación y los servicios externos.
* **Telegram Bot API:** envío de notificaciones al personal del restaurante.
* **Google Fonts:** tipografía utilizada en la interfaz.

---

## ⚙️ Cómo funciona

1. El cliente escanea el código QR correspondiente a su mesa.
2. El sistema carga la página web identificando el número de mesa.
3. El cliente selecciona una acción, como llamar al mozo o pedir la cuenta.
4. La aplicación procesa la solicitud.
5. La información de la acción y el número de mesa se envían al sistema de gestión.
6. El personal recibe una notificación mediante Telegram.
7. La interacción queda registrada para su posterior consulta y análisis.

---

## 📊 Análisis y seguimiento

Además de funcionar como sistema de atención, Get Waiter permite registrar información sobre las interacciones realizadas por los clientes.

Estos datos pueden utilizarse para:

* Analizar la utilización del sistema.
* Identificar las acciones más utilizadas.
* Comparar el uso entre períodos.
* Detectar oportunidades de mejora en la atención.
* Obtener información para la toma de decisiones operativas.
